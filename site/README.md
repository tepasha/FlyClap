# Лендінг FlyClap

Односторінковий сайт про проєкт зі збором донатів: `index.html` (без зовнішніх залежностей, адаптивний, світла/темна тема) + `donate.config.js` (реквізити).

## 1. Вписати реквізити

Відкрийте [`donate.config.js`](donate.config.js) і заповніть **лише** ті способи, якими користуєтесь: банка Monobank, картка, IBAN, Ko-fi, Buy Me a Coffee, PayPal, USDT. На сторінці з'являються тільки заповнені; поки нічого не заповнено — показується «Збір ще не відкрито».

Там же:
- `goal` / `raised` — ціль і зібрана сума (прогрес-бар; `null` — не показувати). Оновлюйте `raised` вручну;
- `budget` — на що підуть кошти (суми можна не вказувати).

Посилання приймаються лише `https://…`; усі значення екрануються — вставити в сторінку код через конфіг не вийде.

## 2. Опублікувати на GitHub Pages (безкоштовно)

1. Репозиторій на GitHub → **Settings → Pages → Build and deployment → Source: GitHub Actions** (один раз).
2. Закомітьте зміни в `main` — workflow [`.github/workflows/pages.yml`](../.github/workflows/pages.yml) збере й опублікує сайт.
3. Адреса: `https://tepasha.github.io/FlyClap/` (з'явиться у вкладці **Actions** → «Landing page»).

Сайт перезбирається сам при змінах у `site/`, схемах і 3D-прев'ю.

## Переглянути локально

```bash
site/build.sh          # збирає _site/ (сторінка + картинки з schematics/ і cad/*/preview/)
xdg-open _site/index.html   # або просто відкрийте файл у браузері
```
